# 底层地图模型 V5

V5只处理原始第3、4张截图，解决两个已确认问题：地图展开后的内部平移，以及图标描边造成的道路误识别。

## 每帧道路配准

即使截图尺寸相同，也使用稳定深灰道路线在 `±12` 像素范围内搜索平移。第3张相对第4张的结果为 `(0,-4)`。

## 人物逻辑位置

人物尖端先应用地图配准偏移。配准后距离不超过3像素的位置吸附为同一逻辑节点。第3、4张因此使用同一人物节点，不再绘制伪移动。

## 道路识别

1. 提取中性深灰候选像素。
2. 生成彩色图标遮挡掩码。
3. 使用最近邻变换校正方向。
4. 只保留长度至少7像素的水平或垂直连续线段。
5. 仅在图标掩码内修复两端均存在证据的缺口。
6. 再次执行长线过滤，排除残余的图标短曲线。
