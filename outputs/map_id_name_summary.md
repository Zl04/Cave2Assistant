# 地图 ID—名称对应关系

来源：合并 APK 基础资源与设备 Hotfix 后的 `Resource/profiles/dataProfile/ProfileClientLevel_<mode>_<difficulty>.lua`，名称通过 `ResourceCN/ProfileLanguage.lua` 解析。

## 字段含义

- `ID`：关卡/地图请求使用的 level ID。
- `mapName`：语言表 ID，不是直接的中文字符串；例如 `1150002 -> 遗忘之穴`。
- `mapAppearanceID`：地图视觉样式 ID，不是地图名称 ID；同一个 appearance ID 可能在不同模式中复用。
- `configMapID`：配置地图布局 ID，主要用于固定地图/活动地图；不等同于 `ID`。
- 唯一索引：`mode + difficulty + ID`。同一个 `ID` 在不同模式中经常代表不同地图。

## 关键源码位置

- `work/warning_logic/decrypted_src/app/datas/PublicDefine.lua:185`：定义 `CAVE_MODE` 数值；正式模式到 24，`MODE_MAX = 25`。
- `work/warning_logic/decrypted_src/app/config/MapLevelConfig.lua`：按 `ProfileClientLevel_<mode>_<difficulty>` 加载并按 level 取记录。
- `work/warning_logic/decrypted_src/app/mapkit/model/MapDataManager.lua:373-379`：从 level 配置读取 `mapName`，并用 `mapAppearanceID` 选择视觉样式。
- `work/map_config_export/decrypted/Resource/profiles/dataProfile/`：地图 ID、语言 ID、样式 ID 的实际配置。
- `work/map_config_export/decrypted/ResourceCN/ProfileLanguage.lua`：语言 ID 到中文名称的映射。
