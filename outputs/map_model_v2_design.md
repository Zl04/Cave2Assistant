# 底层地图模型 V2

## 模块接口

界面只需要两个操作：

```python
model = MapModel.from_images(images)
snapshot = model.snapshot(frame_index)
```

复杂的道路分割、离散变换、逐帧融合、骨架化和连通图构建都隐藏在 `MapModel` 模块内部。

## 状态含义

- `UNKNOWN`：未获得可靠证据，可能是迷雾、空白或尚未探索。
- `ROAD`：截图中的稳定道路底色提供了可通行证据。
- `WALL`：只允许由明确的边界检测器写入；当前四张图不会仅凭空白写入墙壁。

## 每帧处理

1. 将截图配准到公共画布。
2. 用稳定道路底色提取道路区域，并闭合图标造成的小孔洞。
3. 使用最近邻缩放和旋转生成计算栅格，禁止平滑插值。
4. 与历史道路做并集，未知区域不会覆盖历史结果。
5. 对累计道路骨架化，构造八邻接连通图。
6. 度为 1 的图节点作为候选探索前沿。

## 当前限制

仅凭这四张已经打开的地图截图，无法可靠区分“真实死路”和“被迷雾截断的道路”。因此界面中的橙色前沿是候选点，后续需要结合连续截图、人物移动方向或地图展开动画进行确认。
