PaddleOCRApi：
基于PaddleOCR深度封装的完全离线文字识别组件，提供简洁易用的API接口，
支持CPU/GPU，支持C#/C++/Java/Python/Go等多种语言二次开发。
CPU版本完全免费使用，支持多线程并发，支持内存自动回收，支持PPOCRv6/v5/v4模型，支持PaddleOCR-VL1.6/1.5模型，支持一键部署WebApi服务！

https://github.com/PaddleOCRCore/PaddleOCRApi
