# 小地图识别与构建工作台（原型）

双击 `start_map_recognition_viewer.bat` 启动。程序首次打开时会自动载入本次提供的四张截图；也可以点击“打开截图”选择其他按时间排序的 PNG/JPEG 图片。

界面包含：

- 左侧：当前截图、道路像素覆盖层、人物落点与历史位置。
- 中间：经过横向缩放和旋转校正后的简洁道路结构图。
- 右侧：截图内坐标、配准偏移、统一地图坐标、校正后坐标、道路像素和新增道路像素。
- 底部：逐帧时间线，可点击 P1、P2、P3、P4 或使用上一帧/下一帧。

“导出当前结果”会生成当前结构图，以及全部帧的 CSV 和 JSON 坐标数据。

第五版默认底层模型位于 `map_model_v5.py`，当前只载入原始第3、4张截图。每帧都会先利用深灰道路线进行内部配准，再过滤怪物、道具和人物图标，并在校正图中只保留足够长的水平、垂直结构线。人物位置经过配准后会吸附到逻辑道路节点。

模型将计算图与展示图分开：计算图只使用最近邻变换，维护 `UNKNOWN / ROAD / WALL` 离散状态，并逐帧生成连通图和候选探索前沿。当前截图无法可靠证明空白区域是墙，因此模型会保守地将它保留为 `UNKNOWN`。

第二版仍假设第 2 张以后的截图采用相同画布位置，第 1 张通过道路轮廓自动配准到最后一张截图。
