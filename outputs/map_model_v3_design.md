# 底层地图模型 V3：偏移取色

## 为什么替换 V2

灰褐色道路底色与不可行走背景接近，整片分割会制造大面积假道路。V3 改用地图上稳定的深灰结构线，并通过多个偏移采样点确认方向连续性。

## 采样规则

候选颜色范围约为 `RGB(34..72)`，同时要求三个通道差值不超过 12。候选像素还必须满足以下至少一项：

- 左右 `±2` 或 `±4` 像素存在同色支持。
- 上下 `±2` 或 `±4` 像素存在同色支持。

之后只沿水平、垂直方向闭合小间隙。这样不会用方形膨胀把相邻但不连通的道路粘在一起。

## 逐帧累计

四张截图分别生成自己的结构图，然后按公共坐标取并集。界面时间线可以查看从不完整地图到完整地图的每个阶段。历史道路不会因为下一张截图中的迷雾或遮挡而消失。

## 保守状态

未得到偏移取色证据的区域保持 `UNKNOWN`，不会自动写成 `WALL`。候选探索前沿仍需通过后续截图变化确认。
